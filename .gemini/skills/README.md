# راهنمای جامع مهارت‌ها (Skills Directory README)

این سند مرجع رسمی و خلاصه وضعیت تمامی مهارت‌های (Skills) موجود در پوشه `.gemini/skills` است. هدف از این فایل، ارائه شناخت دقیق، سریع و با خطای نزدیک به صفر از هر مهارت و زمان دقیق استفاده از آن برای عامل هوش مصنوعی و توسعه‌دهندگان است.

---

## فهرست مهارت‌ها

### ۱. `ascii-art`
- **ماهیت:** ابزار تولید هنر متنی و بنرهای اسکی (شامل `pyfiglet`, `cowsay`, `boxes` و تبدیل تصاویر به کاراکترهای اسکی).
- **چه زمانی استفاده شود:** وقتی پروژه یا درخواست کاربر نیاز به تولید بنرهای متنی بزرگ، تیترهای اسکی‌ارت، کادربندی‌های متنی یا تصاویر برداری‌شده با کاراکترهای یونیکد داشته باشد.

### ۲. `ascii-video`
- **ماهیت:** پایپ‌لاین پیشرفته تولید ویدیو و انیمیشن‌های هنری ASCII (تبدیل ویدیو، صوت یا تصاویر به فایل‌های MP4 یا GIF رنگی با کاراکترهای ترمینالی).
- **چه زمانی استفاده شود:** هنگام درخواست ساخت ویدیوهای ترمینالی، انیمیشن‌های کاراکتر آرت، موزیک ویژوالایزرهای صوتی-واکنشی یا افکت‌های ویدیویی سبک ماتریکس و اسکی.

### ۳. `code-review-and-quality`
- **ماهیت:** ممیزی و بازبینی چندبعدی کد بر اساس پنج محور کلیدی: صحت (Correctness)، خوانایی (Readability)، معماری (Architecture)، امنیت (Security) و کارایی (Performance).
- **چه زمانی استفاده شود:** قبل از ادغام هر تغییر یا PR، پس از پیاده‌سازی ویژگی‌های جدید، یا هنگام ارزیابی سلامت کدهای نوشته‌شده توسط عامل یا انسان.

### ۴. `composition-patterns`
- **ماهیت:** الگوهای ترکیب‌بندی ری‌اکت (Vercel React Composition Patterns) برای ساخت کامپوننت‌های مقیاس‌پذیر، کامپوننت‌های ترکیبی (Compound Components)، بالا بردن state، اجتناب از انبوه propsهای بولین و سازگاری با React 19.
- **چه زمانی استفاده شود:** هنگام بازفکتورینگ کامپوننت‌های شلوغ با propsهای زیاد، طراحی کتابخانه‌های کامپوننتی قابل‌استفاده مجدد یا معماری لایه‌های UI.

### ۵. `deslop`
- **ماهیت:** ابزار پاک‌سازی کدهای زاید، حشوها یا اصطلاحاً «slop» تولیدشده توسط هوش مصنوعی در شاخه جاری.
- **چه زمانی استفاده شود:** بلافاصله پس از نوشتن یا تغییر کد، برای حذف کامنت‌های اضافه، بررسی‌های دفاعی غیرضروری، کست‌های اجباری `any` و حفظ سبک تمیز کدوبیس.

### ۶. `frontend-design`
- **ماهیت:** قانون‌نامه طراحی فرانت‌اند متمایز و حرفه‌ای؛ شامل دستورالعمل‌های معماری بصری، پرهیز از ظاهر پیش‌فرض و قالبی هوش مصنوعی (Anti-AI Slop)، سلسله‌مراتب تایپوگرافی، حضور قدرتمند در Viewport و دارایی‌های بصری باکیفیت.
- **چه زمانی استفاده شود:** هنگام ساخت یا بازطراحی صفحات وب، لندینگ‌پِیج‌ها، داشبوردها و هر محیط بصری که نیازمند هویت گرافیکی خاص و غیرکلیشه‌ای است.

### ۷. `frontend-ui-engineering`
- **ماهیت:** استانداردهای مهندسی رابط کاربری و اصول پیاده‌سازی فنی کامپوننت‌های فرانت‌اند.
- **چه زمانی استفاده شود:** توسعه ساختاریافته و مهندسی‌شده اجزای رابط کاربری و مدیریت تعاملات DOM در فرانت‌اند.

### ۸. `humanizer`
- **ماهیت:** راهنمای نگارش متون، کپی‌رایتینگ و محتوای کاملاً طبیعی با لحن انسانی.
- **چه زمانی استفاده شود:** زمانی که محتوای متنی، توضیحات یا پیام‌های کاربری نیازمند لحن روان، غیررباتیک و طبیعی باشند.

### ۹. `improve-code-quality`
- **ماهیت:** راهنمای سیستماتیک ارتقا و بهبود کیفیت کد.
- **چه زمانی استفاده شود:** هنگام نیازمندی به بازبینی ساختاری و بالابردن استانداردهای کیفیت کد در پروژه.

### ۱۰. `improve-website`
- **ماهیت:** راهنمای سیستماتیک بهبود وب‌سایت از منظر تجربه کاربری (UX)، طراحی بصری و عملکرد کلی.
- **چه زمانی استفاده شود:** پس از پیاده‌سازی اولیه وب‌سایت برای ممیزی و ارتقای سطح کیفی و صیقل‌دادن جزئیات ظاهری و تعاملی.

### ۱۱. `improve`
- **ماهیت:** پلی‌بوک جامع ممیزی، عارضه‌یابی و بهبود پروژه‌ها (Audit & Improvement Playbook).
- **چه زمانی استفاده شود:** برای اجرای چرخه‌های بهبود ساختاریافته، شناسایی نقاط ضعف و بستن حلقه کیفیت در پروژه‌های نرم‌افزاری.

### ۱۲. `landing-page-design`
- **ماهیت:** اصول و الگوهای طراحی صفحات فرود با نرخ تبدیل بالا (Conversion Rate Optimization).
- **چه زمانی استفاده شود:** ساخت یا بهینه‌سازی صفحات معرفی محصول (Landing Pages) با تمرکز بر جذب مخاطب و هدایت به اقدام (CTA).

### ۱۳. `motion-design`
- **ماهیت:** سیستم جامع طراحی حرکت (Motion Design)، زمان‌بندی‌ها، توابع easing، انیمیشن‌های گام‌به‌گام (Choreography)، اصول دیزنی در UI و میکرواینترکشن‌ها.
- **چه زمانی استفاده شود:** هنگام افزودن انیمیشن‌ها، ترنزیشن‌های صفحات، حالات بارگذاری، بازخوردهای حرکتی دکمه‌ها و المان‌های تعاملی با استفاده از CSS، Framer Motion یا Motion (React).

### ۱۴. `optimize-javascript`
- **ماهیت:** مجموعه قوانین و تکنیک‌های پیشرفته بهینه‌سازی عملکرد جاوااسکریپت و تایپ‌اسکریپت (کاهش سربار GC، بهینه‌سازی لوپ‌ها و ساختار داده‌ها).
- **چه زمانی استفاده شود:** در بخش‌های حساس به سرعت (مانند رندرهای 60FPS، حلقه‌های انیمیشن یا پردازش حجم بالای داده) جهت رفع کندی و بهینه‌سازی CPU/Memory.

### ۱۵. `project-audit`
- **ماهیت:** ابزار ممیزی پروژه و تشخیص انحراف تنظیمات (Config Drift).
- **چه زمانی استفاده شود:** بررسی تطابق فایل‌های کانفیگ، وابستگی‌ها و ساختار پروژه با استانداردهای تعریف‌شده.

### ۱۶. `rams`
- **ماهیت:** اصول طراحی صنعتی دیتر رامز (Dieter Rams - Ten Principles for Good Design) و ممیزی دسترسی‌پذیری (WCAG 2.1) روی کامپوننت‌ها.
- **چه زمانی استفاده شود:** هنگام بررسی کامپوننت‌های UI از نظر پایداری، سادگی، کارایی و استانداردهای دسترسی‌پذیری (A11y مانند alt تصاویر، aria-labelها و مدیریت فوکوس).

### ۱۷. `react-best-practices`
- **ماهیت:** مجموعه قوانین و بهترین روش‌های ری‌اکت (React Best Practices) پیرامون بهینه‌سازی رندرینگ، مدیریت هوک‌ها، جلوگیری از رندرهای اضافی و الگوهای سرور و کلاینت.
- **چه زمانی استفاده شود:** در تمام مراحل توسعه کامپوننت‌های ری‌اکت و نکست.js برای جلوگیری از آنتی‌پترن‌ها و تضمین معماری تمیز.

### ۱۸. `react-doctor`
- **ماهیت:** ابزار عیب‌یابی و رفع باگ‌های ساختاری و رندرهای ناخواسته در ری‌اکت.
- **چه زمانی استفاده شود:** زمان مواجهه با مشکلات پیچیده ری‌اکت، خطاهای هیدریشن یا نشت حافظه در کامپوننت‌ها.

### ۱۹. `react-view-transitions`
- **ماهیت:** راهنمای پیاده‌سازی View Transitions API در ری‌اکت (React 19) برای انتقال نرم بین صفحات و مورف عناصر مشترک (Shared Element Morphing).
- **چه زمانی استفاده شود:** هنگامی که کاربر درخواست انیمیشن‌های روان بین صفحات یا باز شدن مودال‌ها با افکت Morphing دارد.

### ۲۰. `simplify`
- **ماهیت:** متخصص ساده‌سازی کد؛ پالایش و پیرایش کدهای پیچیده، حذف لایه‌های انتزاعی غیرضروری و کاهش پیچیدگی بدون تغییر رفتار برنامه.
- **چه زمانی استفاده شود:** پس از اتمام پیاده‌سازی ویژگی‌ها، برای ساده‌تر کردن کدهای طولانی یا تو در تو و رساندن آن‌ها به ساده‌ترین شکل خوانا و حرفه‌ای.

### ۲۱. `web-performance-auditor`
- **ماهیت:** ممیزی عملکرد وب و بهینه‌سازی شاخص‌های حیاتی وب (Core Web Vitals، LCP، CLS، FID).
- **چه زمانی استفاده شود:** هنگام ارزیابی سرعت لود، بهینه‌سازی منابع استاتیک و تضمین عملکرد روان وب‌سایت در دستگاه‌های مختلف.
