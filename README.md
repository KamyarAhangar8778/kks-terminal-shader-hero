# KKS Terminal Shader Hero

یک صفحه معرفی با پس‌زمینه ماتریسی انیمیشنی، خطوط اسکن مانیتور CRT، افکت گلیچ KKS و بخش‌های معرفی پروژه‌ها و فرم تماس.

---

## قابلیت‌ها

- رندر ۶۰ فریم ماتریس کاراکترها و لوگوی اسکی `KKS` با شیدر اختصاصی WebGL2 (`Wavefront` ASCII Swirl) و مصرف بهینه حافظه
- انیمیشن امواج هارمونیک و واکنش به کلیک کاربر (موج ضربه‌ای `Shockwave` بدون افکت مزاحم هاور)
- پردازشگر تصویر CRT در سطح شیدر WebGL2 با خطوط اسکن، انحنای ملایم و تفکیک رنگی
- کش خودکار فونت‌ها در مرورگر (`Cache Storage API`) برای بارگذاری آنی اطلس کاراکترها
- نشانگر موس سفارشی با حرکت نرم در دسکتاپ
- فرم ثبت سفارش دوکاناله (ارسال مستقیم به ربات تلگرام و سرویس EmailJS به همراه پشتیبان `mailto:`)

---

## تکنولوژی‌ها

| بخش           | ابزار                         | توضیحات                                        |
| :------------ | :---------------------------- | :--------------------------------------------- |
| **Framework** | Next.js (App Router)          | نسخه ۱۵                                        |
| **Language**  | TypeScript                    | تایپ‌اسکریپت در حالت Strict                    |
| **Styling**   | Tailwind CSS                  | نسخه ۴                                         |
| **Motion**    | Motion (`motion/react`)       | انیمیشن‌ها و ترنزیشن‌ها                        |
| **Rendering** | WebGL2 / Three.js / Canvas 2D | شیدر اسکی هیرو، ذرات GPGPU و شبیه‌ساز آتش فوتر |
| **Icons**     | Lucide / Tabler Icons         | آیکون‌های وکتوری                               |

## ساختار فایل‌ها

```text
├── app/
│   ├── globals.css              # استایل‌های سراسری و Tailwind v4
│   ├── layout.tsx               # ساختار روت، متادیتا و فونت‌ها

│   ├── ascii-wordmark/          # رندر کلمه KKS به صورت اسکی

│   ├── custom-cursor/           # نشانگر موس سفارشی

└── types/                       # تایپ‌های پروژه
```

## نصب و اجرا

### پیش‌نیازها

- Node.js نسخه ۱۸.۱۸ یا بالاتر
- npm یا bun

### نصب پکیج‌ها

```bash
npm install
```

### اجرای سرور توسعه

```bash
npm run dev
```

سپس آدرس `http://localhost:3000` را در مرورگر باز کنید.

### بیلد نهایی

```bash
npm run build
npm run start
```

### اجرای تست‌ها و لینت

```bash
npm run lint
npm run test
```
