# KKS Terminal Shader Hero

> **A little cyberpunk. A little CRT nostalgia. A lot of pixels doing their thing.**

یک هیروی تعاملی با حال‌وهوای ترمینال‌های قدیمی و زیبایی‌شناسی سایبرپانک؛ جایی که تایپوگرافی ASCII، شیدرهای WebGL2، نویز تصویری CRT و انیمیشن‌های واکنش‌گرا کنار هم قرار می‌گیرند تا یک تجربه‌ی متفاوت برای معرفی KKS و پروژه‌هایش بسازند.

این پروژه فقط یک پس‌زمینه‌ی متحرک نیست؛ مجموعه‌ای از افکت‌های گرافیکی و تعاملات کوچک است که در کنار هم هویت بصری صفحه را شکل می‌دهند.

## ✦ چه چیزهایی داخلش هست؟

- **ASCII، اما زنده:** لوگوی KKS و ماتریس کاراکترها با شیدر اختصاصی WebGL2 و افکت *Wavefront ASCII Swirl* رندر می‌شوند.
- **موج‌هایی که واکنش نشان می‌دهند:** امواج هارمونیک و افکت ضربه‌ای *Shockwave* با تعامل کاربر فعال می‌شوند؛ بدون اینکه هاورهای مزاحم همه‌چیز را تحت‌تأثیر قرار دهند.
- **حس مانیتورهای CRT:** خطوط اسکن، انحنای ملایم تصویر و جداسازی رنگی، حال‌وهوای نمایشگرهای قدیمی را بازسازی می‌کنند.
- **حرکت با هدف:** انیمیشن‌ها، پارالاکس و نشانگر سفارشی موس در کنار هم کار می‌کنند تا صفحه حس زنده‌ای داشته باشد.
- **بارگذاری هوشمندتر فونت‌ها:** فونت‌ها برای استفاده‌ی دوباره در مرورگر کش می‌شوند تا ساخت اطلس کاراکترها سریع‌تر انجام شود.
- **راه ارتباطی دوکاناله:** فرم تماس از مسیر تلگرام و EmailJS استفاده می‌کند و یک گزینه‌ی جایگزین مبتنی بر mailto هم دارد.
- **بخش‌های معرفی پروژه و تماس:** افکت‌های بصری در کنار محتوای واقعی قرار گرفته‌اند؛ نه به‌جای آن.

## 🧰 تکنولوژی‌ها

| حوزه | ابزار |
| --- | --- |
| Framework | Next.js 15 — App Router |
| UI و زبان | React 19، TypeScript با تنظیمات Strict |
| Styling | Tailwind CSS 4 |
| Animation | Motion |

## 🚀 شروع سریع

### پیش‌نیازها

- Node.js نسخه‌ی **18.18 یا بالاتر**
- npm (یا Bun)

### نصب و اجرا

~~~bash
npm install
npm run dev
~~~

حالا مرورگر را باز کن و برو به [http://localhost:3000](http://localhost:3000).

### ساخت نسخه‌ی Production

~~~bash
npm run build
npm run start
~~~

### بررسی‌های کد

~~~bash
npm run lint
npm run typecheck
npm run format:check
~~~

اسکریپت npm run test در وضعیت فعلی صرفاً پیام می‌دهد که تست‌های خودکار در مخزن وجود ندارند؛ بنابراین آن را نباید به‌عنوان اجرای واقعی یک مجموعه تست در نظر گرفت.

~~~text
app/
  globals.css          استایل‌های سراسری

components/
  ascii-wordmark/      رندر تایپوگرافی ASCII مربوط به KKS
  contact/             فرم و بخش ارتباط

  hero/                لایه‌های Canvas، CRT و گلیچ

lib/                   محاسبات موج، ارسال فرم و ابزارهای کمکی

~~~

## 🔧 چند نکته پیش از انتشار

- برای بررسی کامل فرم تماس، تنظیمات سرویس‌های مربوط به تلگرام و EmailJS را با پیکربندی واقعی پروژه هماهنگ کن.
- شیدرها و افکت‌های گرافیکی به قابلیت‌های مرورگر و پشتیبانی از WebGL2 وابسته‌اند؛ رفتار روی دستگاه‌های مختلف را جداگانه بررسی کن.
- پیش از انتشار نهایی، نسخه‌ی Production را بساز و روی مرورگرها و اندازه‌های صفحه‌ی هدف تست کن.
