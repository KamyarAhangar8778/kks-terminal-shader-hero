# Customer Profile & Jobs-to-be-Done (KKS Systems)

## Job Statement

When a business owner, technical director, or product manager needs a high-performance web developer or custom UI engineer, they want to assess real-world capabilities instantly through a live, interactive experience, so they can confidently hire or order web development solutions without hesitation.

## Job Dimensions

- **Functional Dimension**:
  - Requires immediate visibility into live project demos (Ashkghalam Landing, Markdown Studio).
  - Needs a seamless, zero-friction inquiry transmission form that works across mobile and desktop.
  - Expects fast loading speed, responsive layout, and flawless Persian typography.
  - Underdelivery Note: Traditional portfolios present static images rather than interactive code craftsmanship.

- **Emotional Dimension**:
  - Wants to feel impressed and reassured by the precision engineering, cybernetic aesthetic, and attention to detail.
  - Desires confidence that their own project will receive equal technical rigor.
  - Underdelivery Note: Generic templates create anxiety about low code quality or slow performance.

- **Social Dimension**:
  - Wants to showcase the selected developer's work to team members or stakeholders as proof of quality.
  - Wants to be associated with modern, high-tech engineering standards.
  - Underdelivery Note: Unpolished sites reflect poorly when shared with internal decision-makers.

## Competing Alternatives

| Alternative                      | Why Hired                | Weakness                                                      |
| -------------------------------- | ------------------------ | ------------------------------------------------------------- |
| Static PDF Resume                | Quick to attach in email | Zero proof of interactive performance or UI execution.        |
| Generic WordPress Template       | Cheap and fast to deploy | Heavy bloated code, slow mobile loading, generic visual slop. |
| Social Media Profiles (LinkedIn) | High trust network       | Minimal design control, no live code execution environment.   |
